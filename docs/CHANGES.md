# Source-to-project changes

| Original practical | Portfolio treatment |
| --- | --- |
| BOUSSATA-CP-S1.R | Unified Poisson/NB MLE parameters, grouped residual diagnostics, saved tables and plots; removed hardcoded test conclusions. |
| BOUSSATA-CP-S2.R | Correct annual-aggregate terminology, five explicit positive-cost distributions, validation likelihood and tail comparisons; removed uncalibrated fitted-sample KS p-values. |
| BOUSSATA-CP-S3.R | Renewal-date ages, strict policy/time split, availability-controlled predictors, validation-selected model/threshold and true test metrics. |
| BOUSSATA-CP-S4.R | Train-only Gamma-log GLMs, excluded same-year claim count as a predictor, held-out cost errors and a two-part expected-cost model. |

All workflows now use reusable base-R functions, one command-line runner, recorded environments, aggregate artifacts, baseline comparisons and protocol tests. Assignment prompts, grading language, local absolute paths and prewritten performance claims are absent from the supported project. Original submissions remain separate source material; the repository is the revised implementation.
